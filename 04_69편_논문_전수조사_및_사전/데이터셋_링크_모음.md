### 1. 🥇 AthletePose3D — 가장 추천

**AthletePose3D**는 지금 프로젝트에 가장 잘 맞습니다.

실제 운동선수의 **고강도 스포츠 동작 영상 + 2D/3D pose annotation**을 제공하고, 전체적으로 **1.3M frames / 165K postures** 규모입니다. 데이터 구조에도 실제 `.mp4` 영상과 `.json`, `.npy` motion/pose 데이터가 명시되어 있습니다. 특히 **running motions**가 포함되어 있습니다. ([GitHub](https://github.com/calvinyeungck/AthletePose3D?utm_source=chatgpt.com "GitHub - calvinyeungck/AthletePose3D: Dataset and Code for CVSports at CVPR 2025 paper \"AthletePose3D: A Benchmark Dataset for 3D Human Pose Estimation and Kinematic Validation in Athletic Movements\" · GitHub"))

[AthletePose3D GitHub / 다운로드 안내](https://github.com/calvinyeungck/AthletePose3D?utm_source=chatgpt.com)

**장점**

- 실제 영상
    
- running 포함
    
- 2D pose
    
- 3D pose
    
- COCO keypoints
    
- 학습용 annotation
    
- 스포츠 동작이라 일반적인 사람 영상보다 사용자 목적에 가까움
    

⚠️ 단, 전체 데이터는 바로 받지 말고 **라이선스와 다운로드 방법을 먼저 확인한 뒤 일부 샘플만** 받는 것을 추천합니다.

### 2. 🥈 VideoRun2D — 사용자님 프로젝트와 거의 정확히 일치

이건 이미 사용자님이 찾으셨던 **BiDAlab/VideoRun2D**입니다.

VideoRun2D 자체가 **sprint biomechanics 분석을 위한 markerless 영상 시스템**이고, 실제 실험에서 **5명, 40회의 sprint 영상**을 사용했습니다. MoveNet/CoTracker 기반으로 사람의 관절을 추적하고 trunk, hip, knee 각도를 분석합니다. ([arXiv](https://arxiv.org/abs/2409.10175?utm_source=chatgpt.com "VideoRun2D: Cost-Effective Markerless Motion Capture for Sprint Biomechanics"))

[VideoRun2D 공식 사이트](https://videorun2d.com/?utm_source=chatgpt.com)

[VideoRun2D GitHub](https://github.com/BiDAlab/VideoRun2D?utm_source=chatgpt.com)

**이 데이터가 특히 좋은 이유**

사용자님이 만들려고 하는 게 단순히

> "사진에 사람이 있다"

가 아니라

> **"러닝 영상을 넣으면 사람의 자세/관절을 분석한다"**

쪽이기 때문입니다.

즉 **문제 정의 자체가 VideoRun2D와 굉장히 가깝습니다.**

### 3. 🥉 Synchronized Marker-based & Markerless Motion Capture Dataset

이건 **2026년 공개 데이터셋**이라 상당히 흥미롭습니다.

21명의 참가자를 대상으로 **OptiTrack 7-camera system + 스마트폰 2대**를 동기화해서 촬영했고, 동작에 **running**이 포함됩니다. 원본 영상과 함께 marker-based ground truth, markerless 데이터가 제공됩니다. ([Zenodo](https://zenodo.org/records/18399031 "A Synchronized Dual-System Marker-based and Markerless Motion Capture Dataset for Gait and Fundamental Fitness Activities | Zenodo"))

[Zenodo 공식 데이터셋 페이지](https://zenodo.org/records/18399031)

파일은 현재 다음처럼 공개되어 있습니다.

- `01_participant_metadata.zip` — **10.3 KB**
    
- `02_marker_based_data.zip` — 654.2 MB
    
- `03_markerless_data.zip` — 485.8 MB
    
- `04_code_and_model_data.zip` — 45.4 KB ([Zenodo](https://zenodo.org/records/18399031 "A Synchronized Dual-System Marker-based and Markerless Motion Capture Dataset for Gait and Fundamental Fitness Activities | Zenodo"))
    

**중요:** 여기서는 처음부터 654MB/486MB를 받지 말고 **metadata 또는 파일 내부 구조부터 확인**하는 게 좋습니다.

### 4. Running Event Visualization

마라톤/러닝 이벤트 쪽 영상이 필요하다면 이것도 좋은 후보입니다.

9개 카메라 위치에서 촬영한 **marathon running videos**를 사용하고, runner가 등장하는 구간과 bib number 등을 이용해 annotation/ground truth를 구성했습니다. ([TU Delft Repository](https://repository.tudelft.nl/record/uuid%3A11116a97-f4c9-4671-bb96-400a39273b75?utm_source=chatgpt.com "Running event visualization using videos from multiple cameras | TU Delft Repository"))

[Running Event Visualization — TU Delft Repository](https://repository.tudelft.nl/record/uuid%3A11116a97-f4c9-4671-bb96-400a39273b75?utm_source=chatgpt.com)

다만 이건 **자세 추정용보다는 runner detection/tracking/re-identification** 쪽에 더 적합합니다.
