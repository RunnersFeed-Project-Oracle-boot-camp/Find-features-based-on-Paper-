# 러닝 자세 분석 서비스: 최종 피처 선정 및 산출 설계

> 작성일: 2026년 8월 15일  
> 목적: 논문 근거와 스마트폰 HPE 측정 가능성을 바탕으로 최종 피처를 선정하고, 모델 입력·출력 및 LLM 전달 형식을 정의한다.

---

## 1. 프로젝트 개요

본 프로젝트는 혼자 달리는 러너가 스마트폰으로 자신의 러닝 영상을 촬영하면, HPE(Human Pose Estimation) 모델이 관절 좌표를 추출하고 주요 자세 지표를 계산하여 LLM이 이해하기 쉬운 피드백을 제공하는 서비스다.

### 기본 처리 흐름

1. 스마트폰으로 러닝 영상 촬영
2. HPE 모델로 프레임별 관절 좌표 추출
3. 좌표 평활화 및 착지 시점 검출
4. 최종 피처와 파생변수 계산
5. 품질 정보와 함께 JSON 생성
6. LLM이 사용자용 리포트 작성

### 서비스 적용 원칙

- 초기 검증은 **트레드밀·측면 고정 카메라** 조건에서 수행한다.
- 야외 영상에는 별도의 정확도 검증이 필요하다.
- 집단 평균을 모든 사용자의 정상·위험 기준으로 사용하지 않는다.
- 의료적 진단이나 부상 가능성을 단정하지 않는다.
- 같은 사용자의 동일한 속도·촬영 조건에서 변화를 비교하는 것을 우선한다.

## 3. FEAT-01: 상체 전방 경사각

### 3.1 근거 논문

- **제목:** *The effect of forward postural lean on running economy, kinematics, and muscle activation*
- **저자:** Carson, Aslan, Ortega (2024)
- **DOI:** `10.1371/journal.pone.0302249`
- **원문:** [PLOS ONE](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0302249)
- **대상·환경:** 숙련된 성인 러너 16명, 트레드밀 약 12.9 km/h, 측면 분석

### 3.2 논문에서 사용한 핵심 변수

- `postural_lean_angle`: 발목을 포함한 전신의 전방 기울기
- `torso_flexion_angle`: 골반을 기준으로 한 몸통 굽힘

논문에서는 직립, 중간 기울기, 최대 기울기 조건을 비교했으며 최대 기울기 조건에서 대사비용과 일부 관절·근육 지표가 증가했다.

### 3.3 앱에서 직접 계산할 값

| 변수 | 계산에 필요한 관절 | 단위 |
|---|---|---:|
| `postural_lean_deg` | 어깨 중심, 골반 중심, 발목 기준점 | degree |
| `torso_flexion_deg` | 어깨 중심, 골반 중심, 수직선 | degree |

두 각도는 서로 다른 변수이므로 `FEAT-01A`, `FEAT-01B`로 구분하여 저장한다.

### 3.4 파생변수

| 파생변수 | 정의 |
|---|---|
| `lean_strategy_ratio_pct` | `torso_flexion_deg / postural_lean_deg × 100` |
| `ankle_component_deg` | `postural_lean_deg - torso_flexion_deg` |
| `mean_postural_lean_deg` | 분석 구간 평균 전방 기울기 |
| `max_postural_lean_deg` | 분석 구간 최대 전방 기울기 |
| `lean_variability_deg` | 보폭별 전방 기울기의 표준편차 |
| `baseline_lean_change_deg` | 현재 평균과 개인 기준선의 차이 |

### 3.5 해석 제한

- `postural_lean_deg`가 0에 가까우면 비율이 불안정하므로 Ratio는 `null` 처리한다.
- 논문의 대사비용 회귀식은 해당 연구 조건에서 도출된 식이므로 사용자 대사비용 계산에 직접 적용하지 않는다.
- 각도만으로 햄스트링·둔근의 과부하나 부상 위험을 단정하지 않는다.
- 논문 조건에서 나타난 평균 차이를 정상·비정상 임계값으로 사용하지 않는다.

## 4. FEAT-02: 착지 시 무릎 굴곡각

### 4.1 근거 논문

- **제목:** *Differences in Lower Extremity Kinematics Between High School Cross-Country and Young Adult Recreational Runners*
- **저자:** Reinking et al. (2021)
- **DOI:** `10.26603/001c.18821`
- **원문:** [International Journal of Sports Physical Therapy](https://ijspt.scholasticahq.com/article/18821-differences-in-lower-extremity-kinematics-between-high-school-cross-country-and-young-adult-recreational-runners)
- **측정 환경:** 트레드밀, 선호 속도 약 3.0 m/s, 측면 240 fps 카메라

### 4.2 정확한 변수 구분

| 변수 | 측정 시점 | 의미 |
|---|---|---|
| `knee_flexion_at_ic_deg` | Initial Contact | 발이 처음 지면에 닿는 순간의 무릎 굴곡각 |
| `max_knee_flexion_stance_deg` | Stance Peak | 입각기 중 가장 많이 굽혀진 무릎각 |
| `total_knee_flexion_deg` | IC → Stance Peak | 두 시점 간 굴곡 변화량 |

본 프로젝트의 FEAT-02는 첫 번째 변수인 **Initial Contact 무릎 굴곡각**만을 의미한다.

### 4.3 앱 계산 방법

착지 프레임에서 Hip–Knee–Ankle 세 점이 이루는 내각을 구한 뒤 다음과 같이 굴곡각으로 변환한다.

\[
\text{Knee Flexion}=180^\circ-\text{Hip–Knee–Ankle Inner Angle}
\]

### 4.4 파생변수

| 파생변수 | 정의 |
|---|---|
| `mean_knee_flexion_ic_deg` | 전체 착지 무릎각 평균 |
| `left_mean_knee_flexion_deg` | 왼발 착지 평균 |
| `right_mean_knee_flexion_deg` | 오른발 착지 평균 |
| `lr_difference_deg` | `left - right` |
| `knee_asymmetry_pct` | `abs(L-R) / ((L+R)/2) × 100` |
| `knee_flexion_sd_deg` | 착지 간 무릎각 표준편차 |
| `knee_flexion_cv_pct` | `SD / Mean × 100` |
| `baseline_change_deg` | 현재 평균과 개인 기준선의 차이 |
| `knee_angle_trend_deg` | 영상 전반부와 후반부의 평균 차이 |

### 4.5 해석 제한

- IC 각도와 입각기 최대 굴곡각을 혼합하지 않는다.
- 연구 집단의 평균을 모든 사용자의 정상 기준으로 적용하지 않는다.
- 착지 시점 검출이 부정확하면 측정값을 제공하지 않는다.
- 단일 각도로 충격 흡수 능력이나 부상 위험을 확정하지 않는다.

## 5. FEAT-03: 분당 케이던스

### 5.1 주요 근거 논문

- **원 실험논문:** *Effects of Step Rate Manipulation on Joint Mechanics during Running*
- **저자:** Heiderscheit et al. (2011)
- **원문:** [PubMed Central](https://pmc.ncbi.nlm.nih.gov/articles/PMC3022995/)
- **대상·환경:** 건강한 레크리에이션 러너 45명, 트레드밀, 개인 선호 속도 고정

연구에서는 개인의 선호 케이던스를 기준으로 스텝률을 상대적으로 조절하여 생체역학적 변화를 비교했다. 따라서 본 서비스도 `180 spm` 같은 절대 기준보다 **개인 기준선 대비 변화**를 우선한다.

### 5.2 앱 계산 방법

\[
\text{Cadence (steps/min)}=
\frac{\text{검출된 전체 착지 횟수}}{\text{유효 분석 시간(초)}}\times60
\]

영상의 처음과 마지막에 포함된 불완전 보폭은 제외하고, 첫 유효 착지부터 마지막 유효 착지까지를 분석한다.

### 5.3 파생변수

| 파생변수 | 정의 |
|---|---|
| `cadence_spm` | 분당 전체 착지 횟수 |
| `left_step_count` | 왼발 착지 횟수 |
| `right_step_count` | 오른발 착지 횟수 |
| `mean_step_time_sec` | 연속 착지 사이의 평균 시간 |
| `left_step_interval_sec` | 왼발 착지 간 평균 시간 |
| `right_step_interval_sec` | 오른발 착지 간 평균 시간 |
| `rhythm_asymmetry_pct` | 좌우 평균 착지 간격의 상대적 차이 |
| `cadence_variability_cv_pct` | 착지 간격의 변동계수 |
| `baseline_delta_spm` | 현재 케이던스와 개인 기준선의 차이 |
| `baseline_delta_pct` | `(현재-기준선) / 기준선 × 100` |
| `cadence_trend_spm` | 영상 전반부와 후반부의 케이던스 차이 |

### 5.4 해석 제한

- 케이던스는 반드시 러닝 속도와 함께 저장한다.
- 속도가 다른 영상끼리 케이던스를 직접 비교하지 않는다.
- `180 spm`을 모든 러너의 정답으로 강요하지 않는다.
- 낮거나 높은 케이던스만으로 부상 위험을 단정하지 않는다.

## 6. FEAT-08: 질량중심 대비 착지거리

### 6.1 근거 자료

- **제목:** *An Evidence-Based Videotaped Running Biomechanics Analysis*
- **원문:** [PubMed Central](https://pmc.ncbi.nlm.nih.gov/articles/PMC4714754/)

스마트폰 2D 영상에서는 실제 전신 COM을 직접 측정할 수 없으므로 골반 중심(mid-hip)을 COM의 대리점으로 사용한다.

### 6.2 두 측정 정의의 분리

| 구분 | 변수 | 정의 |
|---|---|---|
| FEAT-08A | COM–발 거리 | 착지 순간 골반 중심과 뒤꿈치 또는 착지점 사이의 수평거리 |
| FEAT-08B | 무릎–발목 거리 | 착지 다리의 무릎과 같은 쪽 발목 사이의 수평거리 |

두 값은 기준점과 의미가 다르므로 하나의 숫자로 합치지 않고 별도 변수로 저장한다.

### 6.3 파생변수

| 파생변수 | 정의 |
|---|---|
| `com_to_foot_distance_px` | 골반 중심과 착지 발 사이의 픽셀 거리 |
| `com_to_foot_distance_cm` | 영상 보정 기준이 있을 때의 실제 거리 |
| `com_to_foot_height_ratio` | `COM–발 거리 / 신장` |
| `com_to_foot_leg_ratio` | `COM–발 거리 / 다리 길이` |
| `knee_to_ankle_distance_px` | 무릎과 같은 쪽 발목 사이의 픽셀 거리 |
| `knee_to_ankle_height_ratio` | `무릎–발목 거리 / 신장` |
| `left_overstride_ratio` | 왼발 착지의 정규화 거리 |
| `right_overstride_ratio` | 오른발 착지의 정규화 거리 |
| `overstride_asymmetry_pct` | 좌우 정규화 거리의 상대적 차이 |
| `overstride_variability_cv_pct` | 착지마다 발생하는 거리의 변동계수 |
| `baseline_change_ratio` | 현재 정규화 거리와 개인 기준선의 차이 |
| `foot_position_relative_to_com` | `behind_com`, `near_com`, `ahead_of_com` |

### 6.4 해석 제한

- 스케일 보정 없이 얻은 픽셀 거리를 사용자 간 비교에 사용하지 않는다.
- 실제 cm를 제공하려면 신장, 기준 물체 또는 카메라 보정 정보가 필요하다.
- 정규화 기준과 착지점 정의를 모든 영상에서 동일하게 유지한다.
- 오버스트라이딩 거리만으로 제동력이나 관절 부하를 직접 계산하지 않는다.

## 7. HPE 모델 및 후처리 데이터 구조

| 단계 | Input | Output | 후처리 | 다음 단계 형식 |
|---|---|---|---|---|
| MediaPipe Pose 또는 RTMPose | RGB 영상 프레임, FPS | 프레임별 관절 좌표와 신뢰도 | 신뢰도 필터링, 보간, 평활화, 좌우 분리 | Landmark JSON |
| FEAT-01 계산 | 어깨·골반·발목 좌표 | 전신 및 몸통 기울기 | 카메라 수평 보정, 구간 통계 | 각도 JSON |
| FEAT-02 계산 | 골반·무릎·발목 좌표 | 프레임별 무릎각 | IC 검출, 좌우 평균 | 각도 JSON |
| FEAT-03 계산 | 발목·뒤꿈치·발끝 좌표, FPS | 발 이동 궤적 | 착지 검출, 중복 제거, 시간 환산 | 시공간 JSON |
| FEAT-08 계산 | 골반·무릎·발목·뒤꿈치 좌표 | 착지 시 수평거리 | IC 검출, 신장·다리 길이 정규화 | 거리·비율 JSON |
| LLM | 후처리 완료 피처 JSON | 사용자용 설명 | 수치 재계산 없이 표현 | 리포트 JSON 또는 텍스트 |

### 프레임별 관절 좌표 예시

```json
{
  "frame": 120,
  "timestamp_sec": 2.0,
  "landmarks": {
    "left_shoulder": {"x": 0.48, "y": 0.31, "confidence": 0.96},
    "left_hip": {"x": 0.51, "y": 0.55, "confidence": 0.94},
    "left_knee": {"x": 0.58, "y": 0.72, "confidence": 0.91},
    "left_ankle": {"x": 0.66, "y": 0.89, "confidence": 0.88}
  }
}
```

```json
  "llm_policy": {
    "compare_with_personal_baseline": true,
    "use_population_values_as_diagnostic_thresholds": false,
    "medical_diagnosis": false,
    "invent_missing_values": false,
    "maximum_feedback_points": 2
  }
}
```

## 10. 야외 적용 전략

1. 트레드밀과 고정 측면 카메라에서 HPE 측정 정확도를 먼저 검증한다.
2. 같은 속도와 촬영 조건으로 개인 기준선을 구축한다.
3. 야외에서는 카메라 움직임·경사·조명·가림을 품질 변수로 기록한다.
4. 품질 기준을 통과하지 못한 값은 숫자를 생성하지 않고 `null` 또는 `not_measurable`로 처리한다.
5. 트레드밀 연구에서 얻은 평균값을 야외 영상의 정상 기준으로 직접 적용하지 않는다.

야외 서비스의 핵심은 실험실 수치를 그대로 재현하는 것이 아니라, **측정 가능한 자세 변수를 일관되게 계산하고 개인의 변화를 안전하게 설명하는 것**이다.

## 11. 최종 결론

본 서비스의 MVP에서는 다음 네 가지를 핵심 피처로 사용한다.

1. 상체 전방 경사각
2. 착지 시 무릎 굴곡각
3. 분당 케이던스
4. 질량중심 대비 착지거리

이 피처들은 측면 스마트폰 영상과 HPE 좌표로 계산할 수 있으며, 서로 다른 자세 특성을 설명한다. 다만 LLM은 자세 값을 직접 계산하거나 의료적 판단을 수행하지 않고, 후처리 코드와 규칙 엔진이 검증한 결과만 설명해야 한다.
